## Supplementary Data

Mapping between the Supplementary Data files of the manuscript and the files in this repository.
All paths are relative to the repository root.

**Supplementary Data 1** — Prevalence of food additives across study participants  
`data/additive_analysis_files/additive_prevalence_across_users.csv`

**Supplementary Data 2** — Non-negative matrix factorization (NMF) loadings for dietary additive mixtures  
`analysis/outputs/supplementary_files/mixtures_loadings.csv`

**Supplementary Data 3** — Food additive and mixture associations with microbial predicted pathways from PICRUSt2  
`analysis/picrust_associations/results/ols_associations_pathway.csv`

**Supplementary Data 4** — Functional category assignment for all food additives  
`analysis/outputs/supplementary_files/Supplementary_Data_4.csv`  
*same content as* `data/additive_name_mapping_v3_merged.csv`

**Supplementary Data 5** — Regression modeling outputs for gut microbiota Shannon diversity analyses  
`analysis/outputs/supplementary_files/Supplementary_Data_5.txt`  
*merged from the individual model summaries:* `analysis/outputs/supplementary_files/model_summary_*.txt`

**Supplementary Data 6** — BIRDMAn effect size estimates and ASV sequences for taxa associated with dietary and additive variables  
`analysis/outputs/supplementary_files/Supplementary_Data_6.tsv`  
*generated by* `analysis/birdman_analysis/generate_supplementary_file_with_ASV_sequences.py`

**Supplementary Data 7** — XGBoost modeling results for classification and regression tasks  
`analysis/outputs/supplementary_files/Supplementary_Data_7.xlsx`  
*merged from the model outputs in* `analysis/machine_learning/ml_outputs/`
