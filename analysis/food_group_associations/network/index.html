This visualization shows food additives as a network, where:

  • Each node represents a food additive (E-code)
  • Node size indicates frequency of occurrence
  • Node color indicates the additive category
  • Links show which additives appear together
  • Link thickness indicates frequency of co-occurrence

You can zoom, drag nodes, and hover for more details.
